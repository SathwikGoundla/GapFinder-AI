# Course Syllabus: Introduction to Programmable Logic Controllers (DEMO CONTENT)

This is original sample material created for the GapFinder AI demo. It is not taken from any textbook.

## Unit 1: PLC Hardware and the Scan Cycle
1.1 Components of a PLC: power supply, CPU, input modules, output modules, programming device.
1.2 Discrete versus analog input and output signals.
1.3 Sinking and sourcing field devices.
1.4 The PLC scan cycle: input scan, program execution, output update, housekeeping.
1.5 Scan time and its effect on fast signals.

## Unit 2: Ladder Logic Fundamentals
2.1 Normally open and normally closed contacts.
2.2 Output coils and the rung concept.
2.3 Series (AND) and parallel (OR) logic.
2.4 Seal-in (latching) circuits for start/stop control.
2.5 Set/reset (latch/unlatch) instructions.

## Unit 3: Timers and Counters
3.1 On-delay timers (TON) and off-delay timers (TOF).
3.2 Retentive timers (RTO).
3.3 Up counters (CTU) and down counters (CTD); preset and accumulated values.

## Unit 4: Safety and Troubleshooting
4.1 Wiring stop buttons as normally closed contacts.
4.2 Why emergency stops must be hardwired.
4.3 Using online monitoring and forcing safely.

Prerequisites: Unit 1 must be understood before Unit 2; Unit 2 before Unit 3.
Assessment: written examination covering all four units.
